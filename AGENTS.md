# AGENTS.md

## Runtime

- `pytest` is available in this repository.
- Always run project commands with `uv run ...`.
- Do not invoke `python`, `pytest`, or other project tooling directly when `uv run` should be used.

## Examples

- `uv run pytest`
- `uv run python main.py --help`
- `uv run python main.py --output-dir generated --output-stem rodent_annotations`
